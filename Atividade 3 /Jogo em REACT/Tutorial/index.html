GuessWord – Um jogo de adivinhação de palavras com React

Neste tutorial você construirá um pequeno jogo de adivinhação de palavras enquanto aprende os fundamentos do React: componentes, props, estado, renderização e histórico.

O que você está construindo?

Você criará um jogo interativo inspirado em jogos como Wordle, onde o jogador tenta descobrir uma palavra secreta em até 6 tentativas.

O objetivo deste tutorial é aprender React na prática enquanto constrói algo real. 

function Tile({ letter, state }) {
  const stateClass = state ? `tile-${state}` : '';

  return (
    <div className={`tile ${stateClass}`}>
      {letter || ''}
    </div>
  );
}
Nota: Se o código ainda parece estranho, não se preocupe. O tutorial explicará cada conceito passo a passo.

Vamos começar com um componente simples chamado Tile.

Código inicial

export default function Tile() {
  return <button className="tile">A</button>;
}

Esse código cria um componente React chamado Tile.

O que é um componente?

Componentes são blocos reutilizáveis que representam partes da interface do usuário.

Construindo o tabuleiro

Um único tile não é suficiente. Precisamos criar uma grade de 6 linhas por 5 colunas.

Fragmentos: React exige que múltiplos elementos sejam envolvidos por um elemento pai.

Passando dados com props

Agora vamos transformar o botão em um componente reutilizável. 

function Tile({ value }) {
  return (
    <button className="tile">
      {value}
    </button>
  );
}

O valor dentro de {value} vem das props. 

<Tile value="A" />
<Tile value="B" />
<Tile value="C" />

Props

Props são parâmetros que permitem passar dados entre componentes.

Tornando componentes interativos

Componentes React podem “lembrar” informações usando state. 

import { useState } from 'react';

function Tile() {
  const [value, setValue] = useState(null);

  function handleClick() {
    setValue('X');
  }

  return (
    <button onClick={handleClick}>
      {value}
    </button>
  );
}

Como useState funciona?

  • value → valor atual
  • setValue → atualiza o valor
  • Ao atualizar, o React renderiza novamente

Elevando o estado

Cada Tile possui seu próprio estado, mas o Board precisa conhecer o estado de todos os tiles.

A solução é mover o estado para o componente pai. 

export default function Board() {
  const [tiles, setTiles] = useState(
    Array(5).fill(null)
  );

  function handleClick(i) {
    const nextTiles = tiles.slice();
    nextTiles[i] = 'X';
    setTiles(nextTiles);
  }
}
Elevação de estado: mover o state para um componente pai é um padrão comum no React.

Por que imutabilidade importa?

Em vez de modificar arrays diretamente, criamos cópias. 

const nextTiles = tiles.slice();

Isso é chamado de imutabilidade.

Benefícios

  • Facilita debug
  • Permite histórico
  • Evita efeitos colaterais
  • Melhora performance do React

Adicionando histórico

Como estamos tratando o estado como imutável, podemos armazenar versões anteriores do jogo. 

const [history, setHistory] = useState([
  {
    guesses: [],
    evaluations: [],
    gameStatus: 'playing'
  }
